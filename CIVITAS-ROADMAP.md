# CIVITAS — ONE WORLD

Independent next-generation city-building game based on Fable Cities (MIT code, CC0 assets). Preserve LICENSE and THIRD-PARTY-NOTICES.md.

## Initial work
- Separate GitHub fork; no reuse of Voxelize or old Babylon client.
- Automatic Vite production build and static publication.
- Touch controls: two-finger pan/pinch, single-finger placement, responsive initial screen.
- First mobile target: Android Chrome, quality=low.

## Next milestones
- Verify deployment and mobile WebGL2 rendering on real devices.
- Optimize asset download and memory footprint; original loads about 160MB.
- Make touch-friendly city tools and compact HUD.
- Rename remaining UI, add CIVITAS identity and save slots.
- Add production chains, trade and settlements with actual server persistence.

This fork is an early playable technical base, not a finished multiplayer CIVITAS game.
